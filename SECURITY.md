# Security policy

agent-man handles configuration that can execute code through hooks, skills, and commands. Treat a
configuration repository like source code: keep it private, review changes, and protect GitHub and
Git credentials.

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/crayonlu/agent-man/security/advisories/new).
Do not put credentials, private repository contents, or exploit details in a public issue.

Security fixes are supported on the latest release. Reports should include the agent-man version,
operating system, Git version, the smallest safe reproduction, and whether symbolic links are
involved. Redact all tokens and configuration values.
